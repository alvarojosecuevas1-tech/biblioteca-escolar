# 📚 Biblioteca Escolar Online

## Descripción del Proyecto

Biblioteca Escolar Online es una aplicación web desarrollada para gestionar y visualizar información de libros de una biblioteca escolar. El sistema permite consultar libros disponibles, aplicar filtros de búsqueda y visualizar estadísticas de manera interactiva.

## Funcionalidades

* Consulta de libros registrados.
* Filtros por título, autor, disponibilidad y año.
* Visualización de estadísticas mediante gráficos.
* Diseño responsive para dispositivos móviles y escritorio.
* Interfaz moderna desarrollada con Bootstrap 5.

## Tecnologías Utilizadas

* HTML5
* CSS3
* JavaScript
* Bootstrap 5
* Chart.js
* GitHub Pages

## Despliegue del Proyecto

El proyecto fue publicado utilizando GitHub Pages como servicio de hosting gratuito.

### Pasos realizados

1. Creación del repositorio en GitHub.
2. Carga de los archivos del proyecto.
3. Configuración de GitHub Pages desde la sección Settings > Pages.
4. Selección de la rama principal (main) y carpeta raíz (/root).
5. Publicación automática del sitio web.

## Optimización Aplicada

* Uso de Bootstrap mediante CDN.
* Uso de Chart.js mediante CDN.
* Implementación de meta etiquetas para SEO básico.
* Diseño responsive adaptable a diferentes tamaños de pantalla.
* Código organizado y optimizado para una carga rápida.
